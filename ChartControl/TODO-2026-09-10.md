**일부만 확인하고 됐다고 판단한 것.**

- `localStorage` 에 값이 있으면 "저장됐다" → 실제로는 화면에 반영이 안 됐다
- 끌 때 줄어들면 "축소된다" → 놓는 순간 되돌아갔다

오늘 소스 검사 시험을 하나 썼는데 `if (!allowMock)` 을 `if (false)` 로 바꿔도 통과했다.
문자열 존재만 봤기 때문이다. **역검증하라** — 고친 것을 되돌려서 시험이 실제로 실패하는지
확인하고, 실패하지 않으면 그 시험은 없는 것과 같다.

## 2. VAT — 세무사 답변 대기 (감사 목록에 남은 유일한 항목)

**하지 말 것: 답변 없이 "VAT 포함" 가격을 만들지 말라.** 잘못 넣으면 세금을 잘못 걷는다.

필요한 답:
1. 해외 소비자 대상 용역 수출이 **영세율**인지 (한국 부가가치세법)
2. EU·영국 **VAT 등록 기준(threshold)** 과 등록 의무 발생 시점

답이 오면 손댈 곳:
- `src/locales/*.js` 의 가격 표기 문구
- `apps/api/src/subscriptions/` 의 금액 계산 (지금은 세금 개념이 아예 없다)

배경: 현재 요금은 `$19/49/99/199` 월정액이고 PayPal 라이브 플랜 ID와 **금액 대조를
부팅 때 검증**한다(`verifiedPlanIds`). 금액을 바꾸면 PayPal 쪽 플랜도 함께 바꿔야 하고,
안 맞으면 그 플랜은 **판매 불가**로 처리된다(의도된 안전장치다).

## 3. 미착수 — 감사 목록 밖에서 발견한 것

### 3-1. 모바일에서 차트 툴바가 사이드바에 덮인다 (고객 영향 있음)

**증상**: 모바일 뷰포트에서 `Compare`, `Lock drawings` 버튼의 **중심점이
`.app-sidebar-v2__scroll` 에 가려져** 누를 수 없다. 관심종목 별표 2개도 테이블
헤더(`th`) 아래에 깔린다.

**확인 방법**: `elementFromPoint(중심x, 중심y)` 가 자기 자신이 아닌 요소를 돌려준다.

```js
// 조작 요소의 중심이 가려졌는지 세는 코드 (Playwright evaluate 안에서)
const els=[...document.querySelectorAll('button,a,[role=button]')]
  .filter(e=>{const r=e.getBoundingClientRect(); return r.width>0&&r.height>0;});
let bad=0;
for (const el of els) {
  const r=el.getBoundingClientRect();
  const top=document.elementFromPoint(r.left+r.width/2, r.top+r.height/2);
  if (top && !el.contains(top) && !top.contains(el)) bad++;
}
```

**주의**: 내가 넣은 `::before` 44px 확장 영역이 원인이 **아니다**(z-index 0, 투명, 가리는
쪽이 전부 실제 요소다). 기존 레이아웃 문제다.

**손댈 곳**: `src/mobile.css` 의 사이드바 z-index / 차트 툴바 위치.

### 3-2. 차트 유휴 재렌더 (성능)

**증상**: 화면을 가만히 둬도 **초당 약 0.2회** `resetData` 가 불려 1000봉을 전부 다시
싣는다. 원인은 `liveVersion` 이 시세 1틱마다 올라가고 `candles` useMemo 가 그것을
의존성으로 갖기 때문이다(`src/app.jsx`).

**이미 시도했고 되돌린 것**: `market.price` 를 의존성에서 빼봤다(커밋 `1a6cb9e`) →
깜빡임이 줄지 않았고(8초/2회 → 20초/4회, **같은 비율**) 마지막 봉이 실시간으로
갱신되지 않는 손실만 생겨 **되돌렸다**(`f853c34`). 같은 시도를 반복하지 말라.

**다음 단서**: `src/chart-kline.jsx:1505` 부근에 `onlyLastBarChanged` 분기가 **이미
있다**. 그 분기가 실제로 도달하는지 **먼저 측정**하라. 도달하지 않으면 조건이 틀린 것이고,
도달하는데도 `resetData` 가 불리면 그 안의 처리가 문제다.

**주의**: 진단 노출(`window.__qtChart`, `__qtChartInfo`)을 **로컬 전용으로 막아 두었다**
(프로덕션에서 주입 스크립트가 차트를 조작할 수 있어서). 측정하려면 로컬에서 띄워야 한다.

### 3-3. PayPal 웹훅 미구현 — 분쟁·차지백이 보이지 않는다

**현재**: 15분 폴링(`subscription-reconcile.ts`)이 승인 누락과 갱신을 처리한다.
이것은 **의도된 선택**이다 — 폴링은 유실되지 않고 PayPal 쪽 설정도 필요 없다.

**문제**: 고객이 PayPal 에 이의를 제기하면(chargeback) 구독 상태가 바뀌지 않으므로
**폴링으로는 알 수 없다.** PayPal 대시보드에만 나타난다.

**준비된 것**: `claimWebhookEvent` / `markWebhookHandled` / `payment_webhook_events`
테이블이 **이미 있고 호출부가 0곳**이다(`subscription-repo.ts` 주석 참고).
멱등성 처리까지 되어 있으니 엔드포인트만 붙이면 된다.

**착수 시점**: 첫 분쟁이 생기거나, 구독이 늘어 대시보드를 매일 볼 수 없게 될 때.

### 3-4. 창 자유 재배치 — 물러선 이유가 있다

**현재 동작**: 편집 모드에서 창을 끌면 따라오고, 놓을 자리가 비어 있으면 놓아진다.
겹치면 원위치로 돌아간다.

**시도했고 성립하지 않은 것**: "겹친 창을 대상이 비운 자리로 보내기"(자리 교환).
계산으로 확인했다 —

```
ai(폭 24)를 오른쪽 아래로 → 겹치는 창 trades(12) + assets(16) = 28 > 24
```

**폭이 다른 창끼리는 단순 교환이 물리적으로 불가능하다.** 연쇄로 밀면 화면이 크게
흔들리고 되돌리기도 어렵다.

**고객 요구는 크기 조절로 해결된다**: AI 창 아래쪽 손잡이를 끌면 11행 → 13행이 되고
아래 포지션 창이 자리를 내준다(실측 확인). 자유 재배치가 꼭 필요하면 격자 재배치
알고리즘을 새로 설계해야 하는 규모다.

## 6. 가장 중요 — 아직 아무도 실제로 써보지 않았다


**오늘 고친 것 중 상당수는 실제로 써봐야만 드러나는 종류였다:**

- AI 가 도구만 쓰고 한 마디도 안 함 → SSE 를 직접 읽어서 발견

## 8. 반복해서 밟은 함정 — 미리 알아두면 시간을 아낀다

1. **CSS 는 잘못된 `var()` 를 조용히 버린다.** 오타가 화면에서 드러나지 않는다.
   오늘 10군데 있었다. 시험 `[0c]`(token-contrast)이 이제 막는다.
2. **자바스크립트는 없는 메서드를 조용히 넘긴다.** `QTI18n.get()`(실제는 `getLocale`)
   때문에 공지 팝업이 아무에게도 안 보였다. 시험 `[0d]` 가 막는다.
3. **선택자를 추측하지 말라.** `.qt-widget a[href^="#/"]` 가 빗나가 스타일이 안 붙었다.
   실제 DOM 을 보고 정하라.
4. **주석이 소스 검사를 망친다.** 이 저장소는 주석이 많아 정규식으로 소스를 읽을 때
   반복해서 걸린다. SVG 주석의 `--` 가 XML 파싱을 깨고, CSS 주석의 `=====` 가 선택자로
   잡혔다. **주석을 먼저 지우고 검사하라.**
5. **닫힌 컴포넌트는 실행되지 않는다.** `{open && <Panel/>}` 안에 복원 로직을 두면
   패널을 열지 않는 한 동작하지 않는다.
6. **`describe.skipIf` 는 본문 실행을 막지 않는다.** 테스트만 건너뛴다. 본문에서
   `process.env.X!` 를 쓰면 수집 단계에서 터지고, **8건 통과인데 종료코드 1** 이 된다.
7. **oklch 는 rgb 도구로 잴 수 없다.** 명암비를 측정할 때 canvas + `getImageData` 로
   실제 픽셀을 읽어야 한다. 알파도 부모 배경 위에 합성해야 한다.
