🔧 백엔드 팀 To-Do · 우선순위별
1. 인증 · 세션 P0
  • OAuth (Google · Apple · GitHub) + Email/PW
  • JWT 발급 · 갱신 · revoke
  • 2FA (TOTP · SMS)
  • 세션 관리 (다중 기기 · IP 추적)
  • 비밀번호 재설정 이메일 발송
2. KYC · 규제 준수 P0
  • 서류 업로드 (S3 · 암호화)
  • ID 자동 인증 (Onfido · Jumio)
  • Face match · Liveness check
  • PEP · Sanctions 리스트 조회
  • AML/CTF 리포팅
3. WebSocket · 시세 P0
  • WebSocket Gateway (Redis pub/sub)
  • 캔들 · 오더북 · 체결 스트림
  • 8 거래소 어댑터
  • 재연결 · Backoff · Rate limit
  • REST fallback
4. 거래 엔진 · 리스크 P0
  • Order matching (또는 거래소 프록시)
  • 주문 유형 (Limit · Market · Stop · OCO · TWAP)
  • 마진 · 청산 · Funding rate
  • 실시간 리스크 스코어 · 자동 청산 큐
  • Position tracking · PnL
5. 지갑 · 자산 P0
  • Hot Wallet (Fireblocks 등)
  • Cold Wallet (Multi-sig 3-of-5)
  • 블록체인 노드 (BTC · ETH · TRC20 · BEP20 · SOL)
  • 입금 감지 (블록 익스플로러 웹훅)
  • Reserve ratio 리컨실
6. AI 모델 P0
  • LLM 백엔드 (GPT-4 · Claude · 자체)
  • SSE 스트리밍
  • Tool calling (chart command)
  • Rate limiting · 토큰 사용량
  • Prompt versioning · A/B
7. 관리자 백엔드 P1
  • 유저 검색 · 정지 · KYC 승인
  • 거래 이상 감지 (ML)
  • 리스크 알림 자동화
  • 감사 로그 (모든 액션)
  • Broadcast 이메일/SMS/Push
8. Referral · 수수료 · 프로모션 P1
  • 티어 자동 계산 (30일 거래량)
  • 프로모션 적용 로직
  • Referral 커미션 (30%)
  • 매월 1일 자동 정산 (USDT)
  • 친구 초대 → 웰컴 크레딧
9. 알림 · CS P1
  • Push (FCM · APNs)
  • 이메일 (SendGrid · SES)
  • SMS (Twilio)
  • In-app WebSocket
  • CS 티켓 (Zendesk 또는 자체)
10. 향후 확장 P2
  • 모바일 앱 (React Native · Flutter)
  • 전략 백테스트 엔진 (server-side)
  • Copy trading (자동 실행)
  • Developer API (3rd-party)
  • 온-체인 지갑 자체 hosting
