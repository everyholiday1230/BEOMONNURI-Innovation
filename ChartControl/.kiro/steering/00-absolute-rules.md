# 절대규칙 (ABSOLUTE RULES) — 위반 불가

이 문서는 QuantumTrade AI 프로젝트에서 작업하는 모든 AI 에이전트와 팀원에게 적용되는
최상위 규칙이다. 다른 모든 지침보다 우선한다.

## 1. 추측·거짓·과장 금지

- **추측 금지**: 코드를 읽지 않고 동작을 단정하지 않는다. 파일을 읽지 않았으면 "읽지 않았다"고
  말한다.
- **거짓 금지**: 실행하지 않은 명령의 결과를 서술하지 않는다. 통과하지 않은 테스트를
  통과했다고 하지 않는다.
- **과장 금지**: "완료", "동작함", "검증됨"은 실제 증거(명령 출력·exit code·테스트 로그)가
  있을 때만 쓴다. 근거가 커밋 메시지나 문서뿐이면 "문서상 그렇게 되어 있으나 미검증"으로
  명시한다.

## 2. 항상 검증

- 코드 변경 후 반드시 `pnpm -r typecheck` → `pnpm -r test` → `pnpm build`를 실행하고
  **exit code를 확인**한다.
- 새 기능·버그 수정에는 테스트를 동반한다.
- 검증할 수 없는 항목(외부 벤더 API, 프로덕션 환경 등)은 "검증 불가 + 그 이유"를 명시한다.
- 보고할 때 다음을 구분한다: ① 실행해서 확인한 것 ② 코드를 읽어서 확인한 것
  ③ 아직 확인하지 못한 것.

## 3. 연관 업무 선제 처리

- 지시받지 않았더라도 요청과 직접 연관된 작업은 알아서 수행한다.
  (예: 라우트 추가 → Zod 스키마 + 테스트 + 문서 + 프론트 계약 정합성까지)
- 단, 아래는 반드시 사전 승인을 받는다:
  - 파괴적 작업 (DB drop, force push, reset --hard, 대량 삭제)
  - 프로덕션 환경 변경
  - 요청 범위를 벗어난 아키텍처 변경 / 기능 축소
  - 외부 벤더·유료 서비스 선정

## 4. 목표

**서비스 출시.** 프론트엔드(레이아웃·버튼·페이지 42라우트)는 이미 완성되어 있다
(`team_delivery/` 참조). 백엔드가 그것을 **실제로 동작하게** 만드는 것이 유일한 목표다.
데모용 스텁이나 placeholder로 "동작하는 것처럼" 보이게 만드는 것은 규칙 1 위반이다.

## 5. 프론트엔드 계약 (변경 금지)

디자인 핸드오프(`team_delivery/HANDOFF_TO_ENGINEERING.md`)에 명시된 UX 계약은 백엔드에서도
강제한다:

1. **Approve Signal ≠ Submit Order** — AI는 절대 주문을 제출할 수 없다. 실주문은 별도의
   다단계 인간 확인을 거친다.
2. **9-gate Risk Check** — 주문 제출 전 9개 검증을 서버에서 수행한다.
3. **KYC 게이팅** — L1 이상만 거래, L2 이상만 출금. 서버에서 강제.
4. **API key Withdraw 권한 금지** — 거래소 API 키에 출금 권한을 요구하지 않으며, 저장 시
   검증한다.
5. **Simulation 모드 표시** — 데모/페이퍼 모드 상태를 API 응답에 항상 포함한다.
6. **거래소 referral 링크는 단일 출처에서 관리** — 8개 거래소.

## 6. 보고 형식

작업 결과 보고 시 다음을 포함한다.

- 실행한 명령과 exit code
- 변경한 파일 경로
- 통과/실패한 테스트 수
- 남은 미검증 항목

## 7. 원본 디자인이 정본 (2026-08-04 지시)

- 원본(`team_delivery/`)의 **레이아웃·배치·버튼·클래스는 그대로** 가져온다. CSS에서 역추적하지 말고 원본 `.jsx`를 열어 마크업을 복사한다.
- 기능은 실제 백엔드에 연결한다. 목업(`QT.*`)만 교체한다.
- 진행률은 `scripts/design-fidelity.py`로 측정한다. 내려가면 회귀다.
- **원본과 내 구현이 다르면 둘 다 남겨 사용자가 고르게 한다.** 단 하나가 사실과 다른 경우(예: 중간값을 "마지막 체결가"로 표기)는 예외로, 정확한 쪽만 남기고 차이를 보고한다.
- 원본에 없고 내가 만든 것은 지우지 않고 별도 버튼·페이지로 추가한다.
- 원본의 예시 숫자는 가져오지 않는다. 자리와 라벨은 남기고 값은 "미연동".
