🚀 새 페이지 만드는 5단계
01 · CHOOSE
템플릿 선택
templates/에서 가장 가까운 페이지 종류를 골라 복사.
→
02 · COMPOSE
컴포넌트 조합
components/에서 필요한 카드·표·폼을 골라 페이지에 붙임.
→
03 · WIRE
데이터 연결
Mock 데이터는 src/mock-app-data.js. 실 데이터는 나중에.
→
04 · REGISTER
라우트 등록
src/app.jsx의 route dispatch + src/page-shell.jsx의 sidebar items.
→
05 · TEST
라우트 접근
#/your-new-route로 이동해서 확인. 사이드바에서도 노출.
