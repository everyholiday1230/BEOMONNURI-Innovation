# 개인정보처리방침

시행일: 2026년 8월 10일 · 버전 1.0

ChartControl(이하 "회사")은 이용자의 개인정보를 중요하게 다루며, 관련 법령을 준수합니다. 이 방침은 회사가 어떤 정보를 수집하고 어떻게 사용하는지 설명합니다.

## 1. 수집하는 정보

회사는 **서비스 제공에 필요한 최소한만** 수집합니다.

### 1.1 계정 정보 (회원가입 시)

| 항목 | 목적 | 보유기간 |
|---|---|---|
| 이메일 주소 | 로그인, 비밀번호 재설정, 중요 공지 | 회원 탈퇴 시까지 |
| 비밀번호 | 인증 (단방향 해시로만 저장하며 원문을 보관하지 않습니다) | 회원 탈퇴 시까지 |
| 이메일 인증 여부 | 계정 보호 | 회원 탈퇴 시까지 |
| 2단계 인증 설정값 | 계정 보호 (이용자가 설정한 경우) | 설정 해제 또는 탈퇴 시까지 |

### 1.2 접속 기록 (자동 수집)

| 항목 | 목적 | 보유기간 |
|---|---|---|
| IP 주소 | 부정 접속 차단, 계정 보호 | 3개월 |
| 브라우저 정보(User-Agent) | 기기별 세션 관리, 이상 접속 확인 | 3개월 |
| 접속 시각 | 위와 같음 | 3개월 |

### 1.3 거래소 연동 정보 (이용자가 연결한 경우)

| 항목 | 목적 | 보유기간 |
|---|---|---|
| 거래소 API 키·시크릿 | 잔고 조회, 이용자의 주문을 거래소로 전달 | 이용자가 삭제할 때까지 |

**암호화하여 저장하며, 화면에는 일부만 표시합니다.** 회사 임직원이 원문을 조회할 수 있는 경로를 두지 않습니다.

### 1.4 이용 기록

| 항목 | 목적 | 보유기간 |
|---|---|---|
| 주문·체결 기록 | 거래 이력 제공, 분쟁 대응 | 5년 |
| 일별 자산 스냅샷 | 자산 추이 그래프 표시 | 1년 |
| 화면 설정(테마·언어·즐겨찾기·차트 템플릿) | 이용 편의, 기기 간 동기화 | 회원 탈퇴 시까지 |
| 약관 동의 기록(버전·시각) | 동의 사실 증명 | 5년 |
| 문의 내역 | 고객 응대 | 3년 |

## 2. 수집하지 않는 정보

- **신분증·여권·얼굴 사진을 수집하지 않습니다.** 회사는 이용자의 자금을 보관하지 않아 실명 확인 의무를 부담하지 않으며, 보관할 법적 근거 없이 신분 정보를 모으면 이용자에게 유출 위험만 생깁니다. 본인 확인은 거래소가 수행합니다.
- **주민등록번호를 수집하지 않습니다.**
- **은행 계좌번호·카드 정보를 수집하지 않습니다.** 회사는 입출금을 취급하지 않습니다.
- **거래소 계정의 출금 권한을 요구하지 않습니다.**

## 3. 처리 근거

- **계약의 이행**: 계정 정보와 거래소 연동 정보는 서비스를 제공하기 위해 필요합니다.
- **정당한 이익**: 접속 기록은 부정 접속을 차단하고 계정을 보호하기 위해 필요합니다.
- **법령상 의무**: 거래 기록과 동의 기록은 분쟁 대응 및 관련 법령 준수를 위해 보관합니다.
- **이용자의 동의**: 위 목적을 넘는 처리(예: 마케팅 메일)는 별도로 동의를 받으며, 동의하지 않아도 서비스를 이용할 수 있습니다.

유럽경제지역(EEA) 거주자의 경우 GDPR 제6조 제1항 (b)(계약 이행), (f)(정당한 이익), (c)(법적 의무), (a)(동의)가 각각 적용됩니다.

## 4. 제3자 제공 및 처리 위탁

회사는 이용자의 개인정보를 **판매하지 않습니다.** 서비스 제공에 필요한 최소한만 아래에 전달합니다.

| 받는 곳 | 전달 항목 | 목적 |
|---|---|---|
| 이용자가 연결한 거래소 | API 키로 인증된 요청(조회·주문) | 이용자의 지시를 거래소에 전달 |
| 이메일 발송 서비스 | 이메일 주소 | 비밀번호 재설정·인증 메일 발송 |
| 클라우드 인프라 제공자 | 서비스 운영에 필요한 데이터 | 서버·데이터베이스 운영 |

법령에 따른 수사기관의 적법한 요청이 있는 경우, 법이 정한 절차와 범위에서만 제공합니다. 그 경우 법령이 금지하지 않는 한 이용자에게 알립니다.

## 5. 국외 이전

서비스의 서버와 일부 처리 위탁사는 대한민국 외에 위치할 수 있습니다. 이 경우 이전되는 항목·목적·보유기간은 위 표와 같으며, 회사는 이전받는 자가 적정한 보호 수준을 갖추도록 계약으로 정합니다.

## 6. 보유 및 파기

- 회원 탈퇴 시 계정 정보와 거래소 연동 정보를 **지체 없이 파기**합니다.
- 위 표에 정한 기간이 지난 정보는 파기합니다.
- 법령이 보관을 요구하는 정보는 그 기간 동안 분리 보관한 뒤 파기합니다.
- 전자적 파일은 복구할 수 없는 방법으로 삭제합니다.

## 7. 이용자의 권리

이용자는 언제든 다음을 할 수 있습니다.

- 자신의 개인정보를 열람·수정
- 거래소 API 키 삭제 (설정 화면에서 직접)
- 처리 정지 요구
- 회원 탈퇴(동의 철회)
- 자신의 동의 기록 확인
- 개인정보를 구조화된 형식으로 받기(이전 요구)

요청은 아래 문의처로 보내 주십시오. **10일 이내**에 처리하고 결과를 알립니다. 요청을 거절하는 경우 그 이유를 설명합니다.

## 8. 안전성 확보 조치

- 비밀번호는 단방향 해시로만 저장하며 원문을 보관하지 않습니다.
- 거래소 API 키는 암호화하여 저장합니다.
- 전송 구간을 암호화합니다(HTTPS).
- 관리자 화면의 조회·변경은 담당자와 시각이 기록됩니다(감사 로그).
- 관리 권한을 업무에 필요한 범위로 분리합니다. 예를 들어 고객 지원 담당자는 이용자 정보를 조회할 수 있으나 계정 상태를 변경할 수 없습니다.
- 접근 권한은 최소한으로 부여하고 정기적으로 점검합니다.

**완전한 보안은 존재하지 않습니다.** 회사는 합리적인 조치를 취하지만, 이용자도 비밀번호를 다른 서비스와 공유하지 않고 거래소 API 키에 출금 권한을 부여하지 않는 것이 중요합니다.

## 9. 쿠키

로그인 상태를 유지하기 위한 세션 쿠키와, 위조 요청을 막기 위한 보안 쿠키만 사용합니다. **광고·추적·행태정보 수집 목적의 쿠키를 사용하지 않으며, 제3자 광고 스크립트를 넣지 않습니다.**

## 10. 아동의 개인정보

만 19세 미만은 서비스를 이용할 수 없으며, 회사는 만 19세 미만의 개인정보를 의도적으로 수집하지 않습니다. 해당 사실을 알게 된 경우 지체 없이 계정과 정보를 삭제합니다.

## 12. 방침의 변경

이 방침을 변경할 때는 **새 버전으로 게시하며 이미 게시된 버전을 수정하지 않습니다.** 중대한 변경은 시행 30일 전에 서비스 내 공지 또는 이메일로 알립니다.
