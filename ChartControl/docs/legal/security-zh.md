# 安全说明

本文件说明本服务**已经实际实施**的安全措施。这里写的不是计划或目标，而是当前正在运行的机制。

## 1. 我们从不保管你的资金

- 你的资金始终留在**你自己的交易所账户**里。我们没有充值地址，没有钱包，也不持有任何钱包的密钥。
- 因此即使我们的系统被攻破，我们也无法动用你的资金 —— 根本不存在动用的途径。

## 2. 我们索取的 API 密钥不含提币权限

- 我们只要求**读取和交易**权限，**有意不要求提币权限**。
- 因此密钥即使泄露，也无法用它提走资金。在交易所创建密钥时，请不要授予提币权限。
- 我们的任何员工、在任何权限级别下，都无法提走你的钱。

## 3. API 密钥加密保存

- 你连接的密钥采用信封加密（envelope encryption）保存，绝不以明文记录。
- 包括管理后台在内，任何地方都不会显示密钥明文。
- 保存密钥后，我们会向交易所真实发起一次查询以确认其可用。不会仅凭保存就标记为「已连接」。

## 4. 账号安全

- 密码以哈希形式保存，不保存明文密码。
- 支持两步验证（TOTP），使用验证器应用中的 6 位验证码。
- 登录尝试有频率限制，连续失败会锁定一段时间。
- 会话 Cookie 带有 Secure 与 HttpOnly 属性；所有改变状态的请求都会校验 CSRF 令牌。
- 暂停账号会立即吊销该账号的会话。

## 5. 下单链路上的防护

- 订单不信任浏览器端的计算，**由服务器重新校验**：最小数量、最小报价单位、价格偏离、杠杆上限、每日上限、持仓数量都在服务器侧检查。
- 实盘订单只有在全部条件满足时才会发送。任一条件不满足就不发送，并在界面上说明原因。
- 系统设有紧急停止开关（kill switch）。一旦启用，所有实盘订单发送立即停止。
- 管理员不能代替你下单、改单或撤单。这是设计如此，不是功能缺失。

## 6. 记录与审计

- 管理员操作会写入只追加的审计日志，记录不会被修改或删除。
- 暂停/启用账号、变更权限、删除凭证等难以撤销的操作，会连同原因一起记录。
- AI 分析的用量会被记录，但**提示词和回复正文不会保存**。

## 7. 传输层保护

- 本服务仅通过 HTTPS 提供。HSTS 头会让浏览器不再尝试明文连接。
- 我们启用了内容安全策略（CSP）、点击劫持防护（X-Frame-Options: DENY）和 MIME 嗅探防护（X-Content-Type-Options: nosniff）。

## 8. 我们不做的事

- 不收集身份证件、自拍或地址证明。身份核验由交易所完成，因此我们这里不存在可能泄露的身份文件。
- 不代你管理资金，不代你自动执行交易。
- 不提供投资建议。

## 10. 本文件的局限

本文件描述的是已实施的措施，并不保证任何攻击都不会成功 —— 绝对安全并不存在。我们也建议你为交易所账户开启两步验证，并且永远不要给 API 密钥授予提币权限。
