# 隐私政策

生效日期：2026 年 8 月 10 日 · 版本 1.0

ChartControl（下称「我们」）谨慎处理你的个人信息，并遵守适用法律。本政策说明我们收集什么以及如何使用。

## 1. 我们收集什么

我们**只收集本服务确实需要的信息。**

### 1.1 账号（注册时）

| 信息 | 用途 | 保存期限 |
|---|---|---|
| 邮箱地址 | 登录、重置密码、重要通知 | 直到关闭账号 |
| 密码 | 身份验证（以单向哈希存储，绝不保存原文） | 直到关闭账号 |
| 邮箱验证状态 | 账号保护 | 直到关闭账号 |
| 两步验证设置 | 账号保护（在你启用时） | 直到关闭或停用 |

### 1.2 访问记录（自动收集）

| 信息 | 用途 | 保存期限 |
|---|---|---|
| IP 地址 | 阻止未授权访问、保护账号 | 3 个月 |
| 浏览器信息（User-Agent） | 按设备管理会话、发现异常登录 | 3 个月 |
| 访问时间 | 同上 | 3 个月 |

### 1.3 交易所连接（如果你连接了）

| 信息 | 用途 | 保存期限 |
|---|---|---|
| 交易所 API 密钥与私钥 | 读取余额、把你的委托转发给交易所 | 直到你删除 |

**加密存储，界面上只显示部分字符。** 我们的工作人员没有任何途径读取明文。

### 1.4 使用记录

| 信息 | 用途 | 保存期限 |
|---|---|---|
| 委托与成交记录 | 展示你的交易历史、处理争议 | 5 年 |
| 每日权益快照 | 绘制你的权益曲线 | 1 年 |
| 界面设置（主题、语言、自选、图表模板） | 使用便利、在你的多台设备间同步 | 直到关闭账号 |
| 同意记录（版本与时间） | 证明你的同意 | 5 年 |
| 客服咨询 | 回复你 | 3 年 |

## 2. 我们不收集什么

- **不收集身份证件、护照或人脸照片。** 我们不保管资金，因此不承担身份核验义务；在没有合法保存依据的情况下收集身份信息，只会让你多承担一份泄露风险。身份认证由交易所完成。
- **不收集身份证号一类的国民识别号码。**
- **不收集银行账户或银行卡信息。** 我们不办理充币与提币。
- **不申请你交易所账户的提币权限。**

## 3. 法律依据

- **履行合同**：账号与交易所连接信息是提供本服务所必需的。
- **正当利益**：访问记录是阻止未授权访问、保护账号所必需的。
- **法定义务**：交易记录与同意记录为处理争议和遵守法定要求而保存。
- **同意**：超出上述用途的处理（例如营销邮件）仅在你另行同意时进行，不同意也可以正常使用本服务。

对于欧洲经济区居民，上述依据分别对应 GDPR 第 6 条第 1 款 (b)、(f)、(c)、(a) 项。

## 4. 共享与受托处理

我们**不出售**个人信息。仅在必要的最小范围内提供给：

| 接收方 | 信息 | 用途 |
|---|---|---|
| 你所连接的交易所 | 使用你的 API 密钥签名的请求（查询与委托） | 转发你的指令 |
| 邮件发送服务商 | 邮箱地址 | 发送密码重置与验证邮件 |
| 云基础设施服务商 | 运行本服务所需的数据 | 服务器与数据库运维 |

当有权机关依法提出要求时，我们仅在法律要求的范围与程序内披露。除法律禁止告知外，我们会告知你。

## 5. 跨境传输

我们的服务器以及部分受托方可能位于你所在国家之外。在这种情况下，所涉项目、用途与保存期限与上文所列一致，并且我们通过合同要求接收方维持充分的保护水平。

## 6. 保存与删除

- 关闭账号时，我们**立即删除账号信息与交易所连接信息。**
- 超过上述期限的数据会被删除。
- 法律要求保存的部分，我们在该期限内**单独存放**，期满后删除。
- 电子文件以无法恢复的方式删除。

## 7. 你的权利

你可以随时：

- 查阅和更正你的个人信息
- 删除你的交易所 API 密钥（直接在「设置」中操作）
- 反对处理或要求限制处理
- 关闭账号（撤回同意）
- 查看你的同意记录
- 以结构化格式获取你的数据（可携带权）

请通过下方联系方式提出请求。我们会**在 10 天内**回复。若我们拒绝某项请求，会说明理由。

## 8. 安全措施

- 密码仅以单向哈希存储，绝不保存原文。
- 交易所 API 密钥加密存储。
- 传输过程加密（HTTPS）。
- 管理端的查阅与变更会连同操作人和时间一并记录（审计日志）。
- 管理权限按职责拆分。例如客服人员可以查看用户信息，但不能修改账号状态。
- 访问权限按最小必要原则授予，并定期复核。

**没有任何系统是绝对安全的。** 我们会采取合理措施，但同样重要的是：请不要在其他网站重复使用同一个密码，也不要给交易所 API 密钥授予提币权限。

## 9. Cookie

我们只使用用于保持登录状态的会话 Cookie，以及用于防止伪造请求的安全 Cookie。**我们不使用广告、追踪或行为分析类 Cookie，也不嵌入任何第三方广告脚本。**

## 10. 未成年人

未满 19 周岁者不得使用本服务，我们也不会在知情的情况下收集其信息。一旦发现账号属于未达该年龄者，我们会立即删除。
