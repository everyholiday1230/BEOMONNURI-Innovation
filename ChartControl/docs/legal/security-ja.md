# セキュリティについて

この文書は、本サービスに**実際に実装されている**対策を説明します。計画や目標ではなく、現在動作しているものだけを記載しています。

## 1. 当社はお客様の資金を預かりません

- お客様の資金は**お客様ご自身の取引所口座**にあります。当社には入金アドレスもウォレットもなく、いかなるウォレットの鍵も保有していません。
- そのため、当社のシステムが侵害されても、当社がお客様の資金を動かすことはできません。動かす手段そのものがありません。

## 2. 当社が求める API キーは出金権限を含みません

- 求める権限は**参照と取引**のみです。**出金権限は意図的に要求しません。**
- したがってキーが漏洩しても、そのキーで資金を出金することはできません。取引所でキーを発行する際、出金権限は付与しないでください。
- 当社のどの従業員も、どの権限レベルでも、お客様の資金を出金できません。

## 3. API キーは暗号化して保存します

- 接続されたキーはエンベロープ暗号化で保存します。平文で記録することはありません。
- 管理画面を含め、キーの平文はどこにも表示されません。
- キーを保存した後、取引所へ実際に一度照会し、利用可能であることを確認します。保存しただけで「接続済み」と表示することはありません。

## 4. アカウントの保護

- パスワードはハッシュで保存します。平文のパスワードは保存しません。
- 二段階認証（TOTP）に対応しています。認証アプリの6桁コードを使用します。
- ログイン試行には回数制限があります。連続して失敗すると一定時間ロックされます。
- セッション Cookie には Secure・HttpOnly を付与し、状態を変更する要求には CSRF トークン検証を適用します。
- アカウントを停止すると、そのアカウントのセッションは即時に無効化されます。

## 5. 注文経路の安全装置

- 注文は画面の計算を信頼せず、**サーバーで再検証**します。最小数量・呼値・価格乖離・レバレッジ上限・1日あたりの上限・保有ポジション数をサーバー側で確認します。
- 実注文は、すべての条件を満たしたときにのみ送信されます。ひとつでも満たさない場合は送信せず、その理由を画面に表示します。
- 緊急停止装置（キルスイッチ）があります。作動させると、すべての実注文送信が直ちに停止します。
- 管理者がお客様に代わって注文を出す・変更する・取り消すことはできません。これは制限ではなく設計です。

## 6. 記録と監査

- 管理者の操作は追記専用の監査ログに記録されます。記録の修正・削除は行いません。
- アカウントの停止・再開、権限変更、資格情報の削除など、取り消しが難しい操作は理由を併せて記録します。
- AI 分析の利用量は記録しますが、**プロンプトと応答の本文は保存しません。**

## 7. 通信の保護

- 本サービスは HTTPS のみで提供されます。HSTS ヘッダーにより、ブラウザは平文接続を試みません。
- コンテンツセキュリティポリシー（CSP）、クリックジャッキング対策（X-Frame-Options: DENY）、MIME スニッフィング対策（X-Content-Type-Options: nosniff）を適用しています。

## 8. 当社が行わないこと

- 本人確認書類・自撮り写真・住所証明を受け取りません。本人確認は取引所が行うため、当社に漏洩し得る本人確認書類は存在しません。
- お客様の資金を代わりに運用しません。自動売買を代行しません。
- 投資助言は提供しません。

## 10. この文書の限界

この文書は実装済みの対策を説明したものであり、いかなる攻撃も成功しないことを保証するものではありません。完全な安全は存在しません。お客様側でも取引所口座の二段階認証を有効にし、API キーに出金権限を付与しないことをお勧めします。
