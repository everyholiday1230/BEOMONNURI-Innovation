# 利用規約

施行日: 2026年9月18日 · バージョン 1.2

## 第1条（本サービスの性質）

本規約は {{BRAND_NAME}}（以下「本サービス」）の利用条件を定めます。

**当社はソフトウェアの開発・提供を行います。** 本サービスは、利用者ご自身が操作するチャート分析
アプリケーションであり、次の機能を提供します。

- 取引所が公開する相場データを受け取り、チャートと指標で表示する機能
- 利用者の質問に対し、チャートと指標が示す内容を説明する AI アシスタント。AI は
  **方向性の見解を含め、チャートに対する自らの読み**を参考情報として述べることがあります
  （第2条の2を参照）
- **利用者ご自身が作成するシグナル・ルール。** 条件（例：「MACD ラインがシグナルラインを
  上抜けた」）を利用者が定義し、本サービスがその条件をローソク足の系列に対して評価し、
  条件が成立した位置をチャート上に表示します。ルールは利用者のものであり、表示は計算結果
  であって、注文は一切行われません
- レイアウト・描画・指標プリセットの保存
- 利用者ご自身が接続した API キーを用いて、**利用者が入力し承認した注文**を利用者ご自身の
  取引所口座へ送信する補助機能

現在チャートは暗号資産市場を対象としています。上場株式や ETF など他の市場への対応を将来追加する
場合があり、その際は本条を更新します。

本サービスは、利用者ご自身の利用のためにライセンスされるソフトウェアです。証券取引所、
ディーラー、登録投資助言業者、資産運用業者、資金決済サービスのいずれでもありません。本サービスが注文を
送信する場合、それは利用者の指示に基づく道具としての動作であり、取引自体は利用者と利用者ご自身の
取引所との間の取引です。当該取引所の規約に従い、注文の受付・執行・価格決定・決済は当該取引所が行います。

## 第2条の2（AI の見解について）

本条は、AI が方向性を含めてチャートの読みを述べることがあるために設けられています。それが何であり、
何でないかを正確にご理解ください。

1. **チャートデータに対するソフトウェアの読みであり、参考情報として提示されます。** 指標の数値と同じく、数多くの入力のひとつです。
2. **助言でも推奨でも勧誘でもありません。** 取引の指示ではなく、取引すべきという示唆でもありません。
3. **利用者個別の事情に合わせたものではありません。** AI は利用者の資金量・レバレッジ・他のポジション・税務上の立場・義務・リスク許容度を知らず、考慮しません。
4. **誤ることがあり、しばしば誤ります。** 過去および現在の価格構造を読むものです。市場が同じ動きを続ける保証はありません。的中率について一切の主張・約束・示唆をしません。
5. **判断は利用者ご自身のものです。** これを読んだうえで注文を出す場合、その注文は利用者ご自身の判断と責任によるものです。
6. **すべての回答に注意書きを表示します。** AI が見解を述べる場合、本サービスはそれが参考情報であり投資助言ではないことを表示します。個別のメッセージに当該表示がないことをもって本規約が変わることはありません。
7. **当該見解の利用により生じた損失について、当社は適用法が許す最大限の範囲で責任を負いません。** 利用者に適用される法により排除できない権利がある場合、その権利が優先します。
