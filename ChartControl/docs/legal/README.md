# 법적 문서 초안

## ★★ 이 문서들은 법무 검토를 받아야 합니다

여기 있는 초안은 **우리 서비스의 실제 구조를 정확히 기술한 것**이고, 법적 효력을
검토받은 문장이 아닙니다. 그대로 게시하지 마십시오.

왜 초안을 만들었는가:
- 아무것도 없는 상태에서 변호사에게 "약관을 만들어 주세요" 하면, 우리 서비스가
  비수탁이라는 사실·KYC 를 하지 않는다는 사실·포인트가 현금이 아니라는 사실을
  다시 설명해야 합니다.
- 초안이 있으면 검토자가 **사실관계를 확인하고 법적 표현을 고치는 일**에
  집중할 수 있습니다.

무엇을 검토받아야 하는가:
1. **관할·준거법** — 어느 나라 법을 따르는지. 초안에는 비워 두었습니다.
2. **사업자 정보** — 상호·주소·사업자번호·대표자. 초안에는 자리표시자입니다.
3. **책임 제한의 유효 범위** — 국가마다 소비자보호법이 다르고, 무제한 면책은
   대체로 무효입니다.
4. **개인정보 국외이전** — 사용자 데이터가 어느 나라 서버에 있는지에 따라
   고지 의무가 달라집니다.
5. **파생상품 서비스 제공의 인허가 여부** — 국가에 따라 우리 형태(주문 전달)가
   규제 대상일 수 있습니다. **이것이 가장 중요합니다.**

## 등록 방법

관리자 계정(super)으로 `/admin/legal` 에서 초안을 만들고, 검토가 끝난 뒤
게시합니다. 아래 파일 내용을 그대로 붙여넣을 수 있습니다.

```
draft-terms-ko.md      이용약관 (한국어)
draft-privacy-ko.md    개인정보처리방침 (한국어)
draft-risk-ko.md       위험 고지 (한국어)
draft-terms-en.md      Terms of Service (English)
draft-privacy-en.md    Privacy Policy (English)
draft-risk-en.md       Risk Disclosure (English)
```

게시하면 되돌릴 수 없습니다(이미 본 사람이 있으므로). 문구를 바꾸려면 새 버전을
만들어야 하고, 그래야 "누가 어느 버전에 동의했는가" 가 남습니다.

## 우리 서비스의 사실 (초안이 기술하는 내용)

검토자에게 이 표를 함께 전달하십시오. 초안의 모든 조항이 이 사실에서 나왔습니다.

| 항목 | 사실 |
|---|---|
| 자금 보관 | **하지 않습니다.** 고객 자금은 고객의 거래소 계정에 있습니다. |
| 입출금 | **제공하지 않습니다.** 고객이 거래소에서 직접 합니다. |
| 주문 | 고객이 연결한 거래소 API 키로 **주문을 전달**합니다. 우리가 대신 판단하지 않습니다. |
| 신분 확인(KYC) | **하지 않습니다.** 자금을 보관하지 않으므로 확인 의무가 없고, 보관 근거 없이 신분증을 모으면 유출 책임만 생깁니다. |
| 수수료 | 고객에게 **받지 않습니다.** 거래 수수료는 거래소가 받습니다. |
| 우리 수익 | 거래소 브로커 리베이트와 추천 가입 보상입니다. 고객이 내는 것이 아닙니다. |
| AI 분석 | 참고 정보입니다. 투자 자문이 아니고, 자동으로 주문하지 않습니다. |
| 포인트 | 사이트 내부 재화입니다. **현금이 아니고 출금·양도할 수 없습니다.** |
| 자동매매 | **하지 않습니다.** 전략 팔로우는 관심 등록이며 신호를 자동 복제하지 않습니다. |
| 거래 대상 | 무기한 선물(파생상품)입니다. 원금 이상 손실이 가능합니다. |
