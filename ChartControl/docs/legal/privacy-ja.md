# プライバシーポリシー

施行日: 2026年8月10日 · バージョン 1.0

ChartControl（以下「当社」）は利用者の個人情報を重要に扱い、関係法令を遵守します。本ポリシーは、当社が何を収集し、どのように利用するかを説明します。

## 1. 収集する情報

当社は**本サービスの提供に必要な最小限**のみを収集します。

### 1.1 アカウント情報（会員登録時）

| 項目 | 目的 | 保有期間 |
|---|---|---|
| メールアドレス | ログイン、パスワード再設定、重要なお知らせ | 退会まで |
| パスワード | 認証（一方向ハッシュのみ保存し、原文は保管しません） | 退会まで |
| メール認証の状態 | アカウント保護 | 退会まで |
| 二要素認証の設定値 | アカウント保護（利用者が設定した場合） | 解除または退会まで |

### 1.2 アクセス記録（自動収集）

| 項目 | 目的 | 保有期間 |
|---|---|---|
| IP アドレス | 不正アクセスの遮断、アカウント保護 | 3か月 |
| ブラウザ情報（User-Agent） | 端末ごとのセッション管理、異常アクセスの確認 | 3か月 |
| アクセス時刻 | 同上 | 3か月 |

### 1.3 取引所連携情報（利用者が接続した場合）

| 項目 | 目的 | 保有期間 |
|---|---|---|
| 取引所 API キー・シークレット | 残高照会、利用者の注文を取引所へ中継 | 利用者が削除するまで |

**暗号化して保存し、画面には一部のみ表示します。** 当社の従業者が原文を閲覧できる経路は設けていません。

### 1.4 利用記録

| 項目 | 目的 | 保有期間 |
|---|---|---|
| 注文・約定の記録 | 取引履歴の提供、紛争対応 | 5年 |
| 日次の資産スナップショット | 資産推移グラフの表示 | 1年 |
| 画面設定（テーマ・言語・お気に入り・チャートテンプレート） | 利便性、端末間の同期 | 退会まで |
| 規約同意の記録（バージョン・時刻） | 同意事実の証明 | 5年 |
| お問い合わせ内容 | お客様対応 | 3年 |

## 2. 収集しない情報

- **本人確認書類・パスポート・顔写真を収集しません。** 当社は利用者の資金を預からないため本人確認義務を負わず、保管する法的根拠なく本人情報を集めれば利用者に漏えいリスクのみが生じます。本人確認は取引所が行います。
- **マイナンバー等の公的個人識別番号を収集しません。**
- **銀行口座番号・カード情報を収集しません。** 当社は入出金を取り扱いません。
- **取引所口座の出金権限を要求しません。**

## 3. 処理の根拠

- **契約の履行**: アカウント情報および取引所連携情報は、本サービスの提供に必要です。
- **正当な利益**: アクセス記録は、不正アクセスを遮断しアカウントを保護するために必要です。
- **法令上の義務**: 取引記録および同意記録は、紛争対応および法令遵守のために保管します。
- **同意**: 上記目的を超える処理（例: マーケティングメール）は別途同意を得て行い、同意されない場合でも本サービスをご利用いただけます。

欧州経済領域（EEA）に居住される場合、GDPR 第6条第1項 (b)(f)(c)(a) がそれぞれ適用されます。

## 4. 第三者提供および委託

当社は利用者の個人情報を**販売しません。** 本サービスの提供に必要な最小限のみを次に提供します。

| 提供先 | 提供項目 | 目的 |
|---|---|---|
| 利用者が接続した取引所 | API キーで認証されたリクエスト（照会・注文） | 利用者の指示を取引所へ中継 |
| メール配信事業者 | メールアドレス | パスワード再設定・認証メールの送信 |
| クラウド基盤事業者 | 本サービスの運営に必要なデータ | サーバー・データベースの運用 |

法令に基づく捜査機関の適法な要請がある場合、法が定める手続と範囲でのみ提供します。その場合、法令が禁じない限り利用者にお知らせします。

## 5. 国外移転

本サービスのサーバーおよび一部の委託先は、利用者の居住国外に所在することがあります。その場合、移転される項目・目的・保有期間は上表のとおりであり、当社は移転先が適切な保護水準を維持するよう契約で定めます。

## 6. 保有および廃棄

- 退会時にアカウント情報および取引所連携情報を**遅滞なく廃棄**します。
- 上表に定める期間を経過した情報は廃棄します。
- 法令が保管を求める情報は、その期間中は分離して保管した後に廃棄します。
- 電子ファイルは復元できない方法で削除します。

## 7. 利用者の権利

利用者はいつでも次のことができます。

- 自己の個人情報の開示・訂正
- 取引所 API キーの削除（設定画面から直接）
- 処理の停止・制限の請求
- 退会（同意の撤回）
- 自己の同意記録の確認
- 個人情報を構造化された形式で受け取ること（ポータビリティ）

ご請求は下記のお問い合わせ先へお送りください。**10日以内**に対応し結果をお知らせします。ご請求をお断りする場合は理由を説明します。

## 8. 安全管理措置

- パスワードは一方向ハッシュのみ保存し、原文は保管しません。
- 取引所 API キーは暗号化して保存します。
- 通信区間を暗号化します（HTTPS）。
- 管理画面での閲覧・変更は担当者と時刻が記録されます（監査ログ）。
- 管理権限を業務に必要な範囲に分離します。例えばお客様対応担当は利用者情報を閲覧できますが、アカウント状態を変更できません。
- アクセス権限は最小限に付与し、定期的に点検します。

**完全な安全は存在しません。** 当社は合理的な措置を講じますが、利用者もパスワードを他のサービスと共用せず、取引所 API キーに出金権限を付与しないことが重要です。

## 9. クッキー

ログイン状態を維持するためのセッションクッキーと、偽造リクエストを防ぐためのセキュリティクッキーのみを使用します。**広告・追跡・行動情報の収集を目的とするクッキーは使用せず、第三者の広告スクリプトを組み込みません。**

## 10. 未成年者の個人情報

満19歳未満は本サービスを利用できず、当社は満19歳未満の個人情報を意図的に収集しません。該当の事実を知った場合、遅滞なくアカウントと情報を削除します。
