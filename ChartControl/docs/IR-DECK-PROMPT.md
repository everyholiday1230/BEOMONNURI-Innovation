# IR 자료 생성 프롬프트 — ChartControl

아래 블록 전체를 복사해서 IR 자료를 만들 AI에게 그대로 전달하세요.

---

## 프롬프트 시작

당신은 시리즈 A 라운드 투자 유치 자료(피치덱)를 제작하는 전문가입니다. 국내 VC와
엔젤 투자자를 대상으로 하는 **20분 발표용 덱**을 만들어 주세요.

### 절대 규칙 — 이것을 어기면 자료를 쓸 수 없습니다

1. **아래 제공된 숫자만 사용하세요.** 새로운 숫자를 만들어내지 마세요.
   시장 규모처럼 제가 제공하지 않은 데이터가 필요하면, 그 자리에
   `[출처 확인 필요: OOO]` 라고 표시하고 비워 두세요.
2. **가정과 사실을 시각적으로 구분하세요.** 가정에는 반드시 `가정` 배지를 붙이고,
   각주에 산출 근거를 적으세요. 투자자는 실사에서 전부 확인합니다.
3. **검증되지 않은 것을 검증된 것처럼 쓰지 마세요.** 아래 "아직 검증하지 못한 것"
   목록의 항목은 절대 성과로 표현하지 마세요.
4. **"AI 트레이딩", "자동 수익", "승률 OO%" 같은 표현을 쓰지 마세요.** AI는 아직
   연결되지 않았습니다. 원금 보장이나 수익 보장을 암시하는 문구는 금지입니다.
5. 언어는 **한국어**. 숫자는 만/억 단위 한글 표기(예: 연 3.9억), 외화는 USD 병기.

### 1. 회사·제품 개요

| 항목 | 내용 |
|---|---|
| 회사 | 범온누리 (BEOMONNURI) |
| 제품명 | **ChartControl** (약칭 CCAI) |
| 한 줄 정의 | 해외 거래소 이용자를 위한 통합 암호화폐 트레이딩 터미널 |
| 제휴 거래소 | KuCoin (브로커 파트너), BitMart |
| 지원 언어 | 영어 · 일본어 · 중국어 (3개 언어, 글로벌 대상) |
| 대상 고객 | 해외 암호화폐 거래소를 쓰는 개인 트레이더 |

**제품이 하는 일**: 차트·주문·포지션·백테스트·거래기록을 한 화면에서 처리합니다.
이용자는 자기 거래소 API 키를 연결해 우리 화면에서 거래합니다.

**핵심 구조 — 우리는 고객 자금을 보관하지 않습니다.** 입금·출금 기능을 의도적으로
만들지 않았고, 자금은 고객과 거래소 사이에만 오갑니다.

### 2. 수익 모델 — 가장 중요한 부분입니다

#### 2-1. 주 수익원: KuCoin 브로커 수수료 분배

**검증된 사실** (KuCoin 공식 자료, 2026년 8월 확인):

| 항목 | 값 |
|---|---|
| KuCoin 선물 수수료 (LV0) | 메이커 0.020% / 테이커 0.060% |
| KuCoin 현물 수수료 (LV0) | 메이커 0.100% / 테이커 0.100% |
| Broker Pro Program(BPP) 분배율 | **거래량에 따라 40% ~ 70%** |
| 우리 현재 등급 | 40% (최저 등급에서 시작) |

**우리 수익 계산** (개인 트레이더는 테이커 비중이 높음 → 테이커 70% / 메이커 30% 가정):

```
선물  실효 수수료 = 0.7×0.060% + 0.3×0.020% = 0.048%
      우리 몫(40%)                          = 0.0192%
      → 거래량 100만 USDT 당 우리 수익 192 USDT

현물  실효 수수료                            = 0.100%
      우리 몫(40%)                          = 0.040%
      → 거래량 100만 USDT 당 우리 수익 400 USDT
```

주의 각주로 넣어 주세요: *KuCoin은 순수수료(net fee) 기준으로 정산하므로, 고객이
KCS 결제 할인을 쓰면 기준액이 줄어듭니다. 보수적으로 10~15% 차감해 보아야 합니다.*

#### 2-2. 고객 1명당 수익 (ARPU) — `가정` 배지 필수

환율 1,400원/USD 기준, 선물 거래 기준입니다.

| 유형 | 월 거래량 | 우리 월수익 | 우리 연수익 |
|---|---|---|---|
| 라이트 (자본 $1천 · 5배 · 1일 1회) | $100,000 | ₩26,880 | ₩32만 |
| 미들 (자본 $3천 · 10배 · 1일 1회) | $500,000 | ₩134,400 | ₩161만 |
| 헤비 (자본 $5천 · 10배 · 1일 2회) | $2,000,000 | ₩537,600 | ₩645만 |

**혼합 가정** (라이트 60% · 미들 30% · 헤비 10%):
```
실거래 고객 1명당  연 매출 ₩1,322,000  (월 약 ₩110,000)
```

#### 2-3. ★ 핵심 슬라이드: 손익분기 고객 수

```
연 매출 2억 달성에 필요한 실거래 고객 = 2억 ÷ ₩1,322,000 = 151명
```

전환 퍼널 (`가정`):

| 단계 | 인원 | 전환율 |
|---|---|---|
| 회원가입 | 약 1,000명 | — |
| 거래소 API 키 연결 | 약 200명 | 20% |
| **실거래 발생** | **151명** | 75% |

**이 슬라이드가 덱 전체에서 가장 중요합니다.** "수만 명이 필요한 사업이 아니라
151명으로 연 2억"이라는 메시지를 시각적으로 가장 강하게 표현해 주세요.

#### 2-4. ★ 자동 마진 개선 — 투자자가 좋아하는 구조

BPP 등급이 40%에서 70%로 오르면 **고객을 늘리지 않아도** 매출이 75% 증가합니다.

| BPP 등급 | 151명 기준 연 매출 |
|---|---|
| 40% (현재) | 2.0억 |
| 55% | 2.75억 |
| 70% (최대) | 3.5억 |

이걸 우상향 계단 차트로 그려 주세요. "규모가 커질수록 단위 경제가 자동으로
개선되는 구조"라는 문구를 붙이세요.

#### 2-5. 제2 수익원: AI 분석 크레딧 (선불 토큰)

이용자가 크레딧을 선불로 구매하고, 차트·지표 분석 1회당 크레딧을 차감합니다.

**원가 — 검증된 단가** (AWS Bedrock, 2026년 8월 확인):

| 모델 | 입력 | 출력 |
|---|---|---|
| Claude Haiku 4.5 | $1 / 100만 토큰 | 약 $5 / 100만 |
| Claude Sonnet 5 | $3 / 100만 | $15 / 100만 |
| Claude Opus 5 | $5 / 100만 | $25 / 100만 |

분석 1회 = 입력 약 2,000 토큰(시세+지표+계정 상태) + 출력 약 800 토큰

```
Sonnet 5 : 2,000×$3/1M + 800×$15/1M = $0.018  ≈ ₩25
Haiku 4.5: 2,000×$1/1M + 800×$5/1M  = $0.006  ≈ ₩8
```

**단위 경제**:

| | 금액 |
|---|---|
| 판매가 (1크레딧 = 분석 1회) | ₩300 |
| 원가 | ₩25 |
| **매출총이익률** | **92%** |

**매출 시나리오** (`가정`):
```
이용자 500명 × 월 50회 × ₩300 = 월 ₩7,500,000
원가                          = 월 ₩  625,000
월 총이익                      =    ₩6,875,000
연 총이익                      =      약 8,250만원
```

**이 모델의 4가지 강점** — 별도 슬라이드로 강조해 주세요:
1. 매출총이익률 92%. 리베이트와 달리 **우리가 가격을 정합니다**
2. **선불 구조** → 크레딧을 먼저 팔고 원가는 나중에 발생 → 운전자본이 플러스
3. **미사용 크레딧 = 낙전수입** (상품권과 동일 구조)
4. **거래소와 무관** → KuCoin 의존을 벗어나는 유일한 수익원

#### 2-6. 전체 수익원 7개

| | 수익원 | 마진 | 개발 상태 | 거래소 의존 |
|---|---|---|---|---|
| ① | 브로커 리베이트 (40→70%) | 100% | **구축 완료** | 높음 |
| ② | AI 분석 크레딧 | 92% | 미개발 | 없음 |
| ③ | 구독제 (기능 등급) | 95%+ | 미개발 | 없음 |
| ④ | 지표·신호 마켓플레이스 (C2C 중개) | 수수료 25% | 미개발 | 없음 |
| ⑤ | 매매방송 (후원·유료방) | 수수료 30% | 미개발 | 없음 |
| ⑥ | B2B 화이트라벨 (터미널 공급) | 높음 | **제품 완료** | 없음 |
| ⑦ | 거래 학습 데이터 | — | **수집 중** | — |

**⑦은 매출이 아니라 진입장벽(moat)으로 설명하세요.** 데이터를 외부에 판매하는
모델로 쓰지 마세요.

### 4. 방어력 (Moat) — 2가지

#### 4-1. ★ 규제 우위 — 고객 자금을 취급하지 않습니다

입금·출금 기능을 **의도적으로 만들지 않았습니다.** 자금은 고객과 거래소 사이에만
오갑니다. 그 결과:

| | 자금 보관 사업자 | **ChartControl** |
|---|---|---|
| VASP(가상자산사업자) 신고 | 필요 | **불필요** |
| 자본금 요건 | 있음 | 없음 |
| 실명계좌 제휴 | 필요 | 불필요 |
| 보안 인증(ISMS 등) | 필요 | 해당 없음 |
| 해킹 시 자금 손실 책임 | 있음 | **구조적으로 없음** |

2026년 8월 VASP 진입 규제가 강화되는 흐름에서, 이 구조는 경쟁사가 나중에
따라오기 어려운 차이를 만듭니다. **비교 표로 그려 주세요.**

#### 4-2. 거래 학습 데이터셋

주문이 일어날 때 **판단 시점의 상태와 결과를 함께** 저장합니다.

- 판단 스냅샷: 지표 설정값, 시세, 호가 스프레드, 계정 위험도, 화면 맥락
- 결과: 체결·취소·청산·손익
- 이용자는 **가명 처리**(무작위 매핑 — 해시가 아니라서 역추적 불가)
- 모의 거래는 제외하고 **실거래만** 학습 대상

경쟁사가 돈으로 살 수 없는 자산입니다. 시간이 지날수록 커집니다.

### 5. ★ 아직 검증하지 못한 것 — 반드시 별도 슬라이드로 넣으세요

투자자는 실사에서 전부 확인합니다. **먼저 밝히는 것이 신뢰를 만듭니다.**
이 슬라이드 제목은 "현재 한계와 해소 계획"으로 하세요.

| 항목 | 현재 상태 | 해소 계획 |
|---|---|---|
| 리베이트 실제 적립 | 브로커 연결(`brokerAttached: true`)은 확인. **입금은 미확인** | 소액 실거래로 1건 검증 |
| 실주문 체결 | 주문이 거래소에 도달함을 확인. **잔고 0으로 시험해 체결은 없음** | 같음 |
| AI 기능 | **미연결** (AWS 자격증명 필요) | 크레딧 모델과 함께 개발 |
| 유료 고객 | **0명** | 베타 모집 |
| 거래소 다각화 | KuCoin 1곳 의존 | BitMart 등 추가 |
| 결제 모듈 | 미개발 (②③④⑤가 모두 이것에 의존) | 최우선 개발 |

**이 슬라이드는 약점 고백이 아니라 "무엇에 투자금이 쓰이는지"의 근거입니다.**
그렇게 프레이밍해 주세요.

### 6. 자금 사용 계획 (2억)

투자 요청액 **2억원**. 아래 항목별 배분은 `[대표 확정 필요]`로 비워 두고,
**틀과 마일스톤 형식만** 만들어 주세요. 각 항목은 반드시 날짜가 있는
마일스톤과 연결되어야 합니다.

권장 항목 (금액은 비워 둘 것):
1. 결제 모듈 + AI 크레딧 개발 → 마일스톤: 유료 결제 첫 매출
2. AI 연결 (AWS) → 마일스톤: 크레딧 판매 개시
3. 고객 확보 (마케팅) → 마일스톤: 실거래 고객 151명
4. 거래소 다각화 → 마일스톤: 2번째 브로커 계약
5. 법률 검토 (마켓플레이스·방송 규제) → 마일스톤: 검토 완료
6. 운영비 (서버·인건비)

### 7. 발표 구성 — 20분 / 슬라이드 14장 + 부록

**핀테크 덱은 규제 노출 · 수익 구조 · 컴플라이언스를 반드시 다뤄야 합니다.**

| # | 슬라이드 | 시간 | 핵심 메시지 |
|---|---|---|---|
| 1 | 표지 | — | 제품명 · 한 줄 정의 · 투자 요청액 |
| 2 | **이미 만들었습니다** | 1분 | 1,878 테스트. 아이디어가 아님 ← **가장 강한 신호로 시작** |
| 3 | 문제 | 1분 | 도구가 흩어져 있다 (차트/주문/기록 분리) |
| 4 | 해결책 · 제품 시연 | 3분 | **실제 화면 캡처.** 슬라이드보다 제품 |
| 5 | 시장 | 2분 | `[출처 확인 필요]` — 규모 데이터 비워 둘 것 |
| 6 | 수익 구조 (2-1) | 2분 | 수수료 → 우리 몫 흐름도 |
| 7 | **151명 = 2억** (2-3) | 2분 | 덱 전체의 핵심 |
