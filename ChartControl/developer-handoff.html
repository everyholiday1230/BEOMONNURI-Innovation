Widget-to-Widget Relations SPEC
// EVENT BUS — widgets never call each other directly.

on symbol.change (sym)
  → Main Chart reloads candles for sym
  → Order Book, Recent Trades resubscribe
  → Order Entry resets prefill + updates fee model
  → AI Copilot updates context, invalidates in-flight signal
  → Symbol Header updates identity block

on timeframe.change (tf)
  → Main Chart, Mini Chart re-render
  → Indicators recompute
  → AI Copilot context.tf = tf (does NOT auto-invalidate signals unless attribute-locked)

on signal.update (signal)
  → Chart Overlays synced (Entry / SL / TP1-3 / Marker / Invalidation line)
  → Signal Card re-render
  → Order Draft refresh only if user explicitly requested re-linking
  → Positions.signals tab upsert row

on preset.change (id)
  → LayoutEngine.applyPreset(id) — replaces geometry + visibility
  → dirty = true until user saves
  → AI Copilot retains conversation history
  → In-flight signal preserved and re-rendered in new layout

on connection.state (state)
  → Symbol Header connection cluster color/label
  → All widgets may enter Stale / Reconnecting decoration
  → Order Entry disables Submit; toast on reconnect

on theme / brand / longshort.change
  → CSS custom-props flip; no widget-level re-render required.

Priority Preservation Rules SPEC
  1. 가격·포지션·리스크 정보는 어떤 화면 크기에서도 항상 표시.
  2. 차트는 최소 40% 폭 확보 (밑으로 접힘 금지).
  3. Order Entry는 화면 폭 < 1200px에서 Right → Bottom drawer 전환 옵션 (사용자 설정).
  4. AI Copilot 상태 (Docked · Floating · Collapsed)는 사용자가 명시적으로 토글하지 않는 한 preset이 결정.
  5. Positions 테이블은 폭 < 1024px에서 card layout으로 자동 전환.
  6. Tooltip은 hover 시에만 표시되므로, 정보를 tooltip에만 넣지 말 것 (touch 미지원).
  7. Layout Edit Mode는 최소 1280px 이상에서만 활성 (그 이하에서는 preset 선택만 허용).
